# Development of Software for User Authority Delimitation

## Описание проекта
Данный проект представляет собой учебное программное обеспечение для разграничения полномочий пользователей. Реализованы два режима работы: администратор (ADMIN) и пользователь (USER). Программа обеспечивает управление учетными записями и аутентификацию.

## Основной функционал
- Два режима работы: администратор и пользователь.
- Фиксированный логин администратора (ADMIN).
- ADMIN: смена пароля, просмотр и управление пользователями.
- USER: смена пароля.
- Ограничения на ввод пароля (замена символами '*', завершение работы при трех ошибках).
- Сохранение данных пользователей в файл.
- Требования к сложности пароля (длина, символы, уникальность).
- Поддержка сертификатов на USB-носителях.
- Контроль сигнатуры компьютера для защиты от несанкционированного доступа.
